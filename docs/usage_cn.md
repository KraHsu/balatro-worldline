# 使用指南

[返回中文版首页](../README_CN.md) · [English](usage.md)

普通牌局默认在稳定状态自动建立世界线，无需手动输入种子。「选项 → 世界线设置」可以关闭自动创建；中途开启只记录之后的进度。

按 F6 打开世界线。右键拖动平移，滚轮缩放；缩略图支持拖动视口和以鼠标位置为中心缩放。左键框选，Ctrl 多选，Shift 连选路径。选择节点后使用「世界线收束」恢复；选择两个节点可以「对比」或配置录像范围。

节点表示进入阶段，连线汇总阶段中的购买、出售、刷新、开包、出牌和弃牌。可添加自定义书签；折叠区域保留首尾卡牌，只允许折叠不跨分叉的线性路径。操作顺序和完整局面相同的路线可以复用分支。

Ctrl+Z 撤回最后一次不可逆操作，保留已访问的历史。选中卡牌不计入撤回。普通单步撤回不额外标记种子局；非种子局连续撤回需要在两秒内再次按键确认，已是种子局时不提示。主动使用世界线、回溯、存档和分享功能会标记种子局，遵循原版成就与发现规则；被动记录和修改自动创建设置不会。

数据目录是 `%APPDATA%/Balatro/WorldLine`。存档管理支持重命名、备份、删除整个记录或分支、导出指定分支及其前置路线。删除前会验证备份；恢复备份创建新的记录。分享文件后缀为 `.worldline.json`。从 0.6.3 或更早版本升级，请先按[迁移说明](development.md#legacy-data-migration)转换数据。

录像需要单独安装 FFmpeg。选择同一路线的起止节点，配置速度、帧率、输出尺寸和卡牌信息停顿。可用文件选择器配置 FFmpeg 与输出目录，也可手动输入。导出期间当前牌局暂停，独立后台进程生成无声 MP4，Esc 可取消。2K 资源占用更高；短片仍有独立进程启动成本。

旧记录缺少完整边界或内部顺序时显示橙色警告，仍可按已有输入导出。实际缺少目标卡牌、玩法局面或随机状态不一致时会指出问题所在。旧路线完全没有跳过盲注时，未使用的轨道标签缓存差异不阻止录像，其余状态继续校验。
